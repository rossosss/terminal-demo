# Документация без отдельного сервера

Документ подготовлен через Docs Portal. Запрос подтверждается владельцем в GitHub Issue, после чего GitHub Actions создаёт отдельную ветку и Pull Request.

Изменения попадают в main только после review и merge. Портал сверяет SHA источников по расписанию и публикует обновлённую документацию.
