# Terminal

Каноническая документация находится в `docs/`. После push изменений docs в main workflow уведомляет docs-portal. Изменения только src не запускают его.

Настройка: secret DOCS_PORTAL_TOKEN (Contents: write только центрального репозитория); variable DOCS_PORTAL_REPOSITORY = owner/docs-portal. Полная инструкция — в README центрального проекта.
